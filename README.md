# 衡控体重原型演示

这是一个可本地运行的体重管理作品集 Demo，已经升级为带后端账号体系的版本。

## 已实现

- 启动页自动进入体重首页
- 五个底部页面：体重、饮食、趋势、聊天、个人中心
- 注册 / 登录账号
- 密码加密保存
- SQLite 数据库存储用户与体重记录
- 登录后新增体重记录会保存到后端，刷新后仍可读取

## 启动完整前后端版

在项目目录运行：

```bash
python server.py
```

然后浏览器访问：

```text
http://localhost:5174
```

## 演示流程

1. 打开 `http://localhost:5174`
2. 点击最右侧个人中心
3. 点击“注册/登录”
4. 注册一个账号，密码至少 6 位
5. 回到第一个体重页，点击右下角加号新增体重
6. 刷新页面或重新登录后，记录仍会保留

## 数据文件

本地数据库文件会生成在项目目录：

```text
hengran.sqlite3
```

这是本地演示数据库，不需要额外安装 MySQL 或其他数据库服务。
